# EEG Multi-Target Regression on LEMON EEG Data

## 1. Project Overview
This project implements an end-to-end EEG machine learning pipeline to predict multiple behavioral and cognitive targets from resting-state EEG recordings. It uses bandpower feature engineering and a Random Forest multi-output regression approach to model several outcomes at once. The codebase is modular, reproducible, and portfolio-ready for applied ML and neuroinformatics workflows.

## 3. Dataset Assumptions
- EEG data comes from the LEMON dataset (or a similar resting-state EEG dataset).
- EEG `.fif` files are stored in `data/`.
- A phenotype CSV file is available with subject-level metadata and labels.
- Target variables include: `attention`, `fluid_intelligence`, `working_memory`, and `executive_function`.

## 4. Preprocessing and Feature Extraction
The feature pipeline extracts bandpower across the following EEG bands:
- `delta`
- `theta`
- `low_alpha`
- `alpha`
- `high_alpha`
- `low_beta`
- `beta`
- `high_beta`

Pipeline flow:
load -> preprocess -> PSD -> bandpower -> flatten -> append age/gender -> build X and Y

## 5. Model Training
Modeling uses `RandomForestRegressor` wrapped in `MultiOutputRegressor` for simultaneous prediction of all targets.

Training workflow:
load -> build dataset -> train -> evaluate -> save

## 6. Evaluation Metrics
Model performance is reported per target using:
- R2 score
- RMSE
